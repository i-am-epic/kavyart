## Tips
- Use the highest resolution photos you have
- The website uses `mix-blend-mode: multiply` to seamlessly blend the paper backgrounds with the cream card backgrounds — no manual background removal needed!
- For best results, try to keep image sizes under 1MB each (compress with tools like TinyPNG)
